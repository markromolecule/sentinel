# Sentinel Architecture Decision Records (ADRs)

This directory stores durable architecture decisions for the **Sentinel** platform.

## Writing an ADR
1. Create a new file named `NNNN-kebab-case-title.md` (e.g. `0001-auth-flow.md`).
2. Follow the canonical template at [`context-factory/docs/templates/Decision.md`](file:///Applications/XAMPP/xamppfiles/htdocs/sentinel/context-factory/docs/templates/Decision.md).
3. Record the context, decision outcome, consequences, and compliance verification.
4. Index the new ADR below.
